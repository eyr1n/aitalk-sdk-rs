# aitalk-sdk-rs

A.I.VOICE 1 `AITalk_SDK.dll` Rust Binding Library.

## Crates

- `aitalk-sdk-sys` - Low-Level Unsafe Rust Binding of `AITalk_SDK.dll`
- `aitalk-sdk` - High-Level Safe Rust Binding of `AITalk_SDK.dll`
- `examples/server` - HTTP Server built with axum
